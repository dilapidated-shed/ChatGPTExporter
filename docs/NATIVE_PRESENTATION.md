# Read-only presentation adapter

`native/cgw_presentation.h` exposes a bounded snapshot of an existing native C1
archive. It acquires the current workspace's shared lock and calls the actual
read-only disk reconstruction, then requires the selected conversation and its
normalized hash in that verified inventory. It compares the selected bytes to
the immutable object before publishing any messages. Source and inventory
digests remain accessible through the view.

The adapter retains normalized ordering, message/node identities, author roles,
selected-branch membership, ordered content parts, code language and asset
references. Unknown roles and unsupported parts stay explicit; exact raw part
spans remain inspectable. Decoded text has an explicit byte length, including
embedded NUL. The caller supplies output capacity. The snapshot is limited to
4 MiB and the existing parser's token/work limits; it does not grow with an
unbounded conversation. A larger source is refused rather than truncated.

This API has no request, credential, connection or mutation operation. Opening
and verification must run on a worker. It is a source adapter for a native
presentation consumer, not an Android viewer by itself. Native C1 archives are
supported; browser/offline V2 envelopes retain their different existing verifier
and are not silently accepted under the native C1 contract.

Independent expectations are owned by ai-ci's native-presentation acceptance.
The producer script uses an archive generated by the existing synthetic TLS
capture suite and checks a corrupt-source refusal plus a separately compiled
wrong-role mutation. Host execution does not establish a user archive, Android
integration, live account, attachment availability or full-account completion.
