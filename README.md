# ChatGPTExporter

This fork is being rebuilt around an observed, documented ChatGPT web contract.

## Current repository layout

- `docs/chatgpt-web-api/` — pinned source mirrors and our API/behavior notes.
- `reference-code/` — the inherited `siraht/ChatGPTExporter` implementation, preserved intact as reference material.

The code under `reference-code/` is **not the current implementation or design authority**. It is retained because it contains useful tests, archival ideas, fixtures and prior observations that may be reused selectively.

No replacement exporter implementation has been adopted yet.
